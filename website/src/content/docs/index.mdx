Sverka is a code-first TypeScript pipeline engine. Author workflows in
code — not YAML, not config files, not prompts. Execute them locally
through a native engine. Lower the same Definition Graph to GitHub Actions
or GitLab CI.

AI agents leverage Sverka through skills and CLI. An agent says `sverka run
--entry ci --format json` — Sverka builds the pipeline, runs everything
locally, and returns structured findings. The agent spends ~50 tokens, not
~5000 (estimates vary by repo, tool count, and model).

## How it works

```text
author → plan → run → synth
```

1. **Author** — Define your pipeline in `sverka.config.ts` using the Construct,
   SDK, or Decorator API. Steps, dependencies, artifacts, triggers.
2. **Plan** — `sverka plan` binds the Definition Graph to a Run Plan. Resolves
   reachable steps from entry roots.
3. **Run** — `sverka run` executes the Run Plan through the native engine.
   Local, parallel, with artifact and scalar transfer between steps.
4. **Synth** — `sverka synth --target github` lowers the same workflow to
   GitHub Actions YAML. Or `--target gitlab` for GitLab CI.
