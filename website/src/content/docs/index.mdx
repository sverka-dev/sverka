> **⚠️ Work in progress — pre-alpha.** Sverka is under active development and
> not ready for production use. APIs may change without notice.

Sverka is a portable workflow runtime. Define workflows as TypeScript code,
execute them locally through a native engine, and compile the same definition
to GitHub Actions, GitLab CI, Temporal, Dagger, or Inngest. No external
infrastructure required — the runtime is a single process.

AI agents use Sverka through a skill or the CLI. One command replaces
dozens of tool-call round-trips: `sverka run --entry ci --format json`
builds the pipeline, runs everything, returns structured findings. The
agent delegates orchestration; Sverka handles execution.

## How it works

```ts
import { Project, Pipeline, ShellStep, Entry } from "@sverka/workflow";

const proj = new Project("ci");
const p = new Pipeline(proj, "ci");

new ShellStep(p, "lint", { command: "bun run lint" });
new ShellStep(p, "build", { command: "bun run build", dependsOn: ["lint"] });
new ShellStep(p, "test", { command: "bun run test", dependsOn: ["build"] });

new Entry(p, "on-push", { trigger: { kind: "push" }, roots: ["test"] });

export default proj;
```

```text
author → plan → run → compile
```

1. **Author** — Define your workflow in TypeScript using the Construct API.
2. **Plan** — `sverka plan` binds the Definition Graph to a Run Plan.
3. **Run** — `sverka run` executes locally through the native engine.
4. **Compile** — `sverka compile --target github` lowers to CI YAML.
