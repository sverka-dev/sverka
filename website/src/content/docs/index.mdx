> **⚠️ Work in progress — pre-alpha.** Sverka is under active development and
> not ready for production use. APIs may change without notice.

Sverka is a framework for running local checks. Define your checks — lint,
typecheck, tests, security scans — as TypeScript code. Run them locally
through a native engine. Get structured findings back. Compile the same
definition to GitHub Actions or GitLab CI when you need to.

No external infrastructure. No cloud API calls. No Temporal server. The
runtime is a single process that executes your workflow and returns
findings in SARIF, JSON, or HTML.

## How it works

```ts
import { Project, Pipeline, ShellStep, Entry } from "@sverka/workflow";

const proj = new Project("my-project");
const ci = new Pipeline(proj, "checks");

new ShellStep(ci, "typecheck", { command: "bun run typecheck" });
new ShellStep(ci, "lint",      { command: "bun run lint", dependencies: [{ kind: "control", producer: "typecheck" }] });
new ShellStep(ci, "test",      { command: "bun run test", dependencies: [{ kind: "control", producer: "lint" }] });

new Entry(ci, "on-push", { trigger: { kind: "push" }, roots: ["test"] });

export default proj;
```

```text
define → run → view → compile
```

1. **Define** — Write your checks as TypeScript code using the Construct API.
2. **Run** — `sverka run` executes locally. Get findings in SARIF, JSON, or HTML.
3. **View** — `sverka view` opens an interactive TUI. `sverka ui` starts a web dashboard.
4. **Compile** — `sverka compile --target github` lowers to CI YAML when you need it.

## Quick start

```bash
# Install
bun add -g @sverka/cli

# Initialize a project
sverka init

# Run checks locally
sverka run --evaluate

# Run with SARIF output
sverka run --format sarif

# View findings in terminal
sverka view .sverka/findings.sarif

# Start web dashboard
sverka ui

# Compile to GitHub Actions
sverka compile --target github
```
