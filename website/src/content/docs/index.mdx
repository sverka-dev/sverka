Sverka is a composable workflow SDK, local CI runtime, and multi-target compiler for software verification. Write your verification pipeline as TypeScript, run it on your machine, and compile the same workflow to GitHub Actions, GitLab CI, and more.

## What you get

<CardGrid stagger>
  <Card title="TypeScript-first" icon="seti:typescript">
    Compose pipelines, parallel steps, conditional runs, and matrices with a typed SDK.
  </Card>
  <Card title="Local execution" icon="rocket">
    Run checks in Docker, Podman, or on the host without touching a CI provider.
  </Card>
  <Card title="Compile anywhere" icon="external">
    Emit GitHub Actions, GitLab CI, or other targets from the same source of truth.
  </Card>
  <Card title="Normalized findings" icon="approve-check">
    SARIF, fingerprints, baselines, and policy verdicts in one model.
  </Card>
</CardGrid>
