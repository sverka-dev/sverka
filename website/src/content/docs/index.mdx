An agent says `/sverka build, then lint, then sonar + codacy + trivy, output findings as SARIF`. Sverka builds the pipeline, runs everything locally, and returns structured findings. The agent spent **50 tokens, not 5000**.

## Why Sverka

<CardGrid stagger>
  <Card title="AI-first" icon="approve-check">
    CLI-native + structured JSON. Say `sverka run --entry ci --format json` — Sverka handles the rest. The agent declares **what** to verify, not **how**. Claude plugin and AI skill integrations are planned.
  </Card>
  <Card title="Token-efficient" icon="seti:typescript">
    Delegate orchestration to the pipeline, not the LLM. One command replaces 6+ tool-call round-trips. ~97% token reduction per verification run.
  </Card>
  <Card title="Localhost engine" icon="rocket">
    Everything runs locally. No cloud, no remote API calls. Host or container runtime. Topological scheduling, parallel steps, structured findings.
  </Card>
  <Card title="TypeScript SDK + DSL" icon="seti:typescript">
    Author workflows in code. Three equivalent APIs: Construct (CDK-style), SDK (composables), Decorator (`@step`, `@pipeline`, `@entry`).
  </Card>
  <Card title="CLI" icon="forward-slash">
    `sverka plan`, `run`, `check`, `discover`, `validate`, `graph`, `synth`, `policy`, `doctor`. One tool, full pipeline. JSON output for agent consumption.
  </Card>
  <Card title="Compile to CI" icon="seti:yaml">
    Same workflow lowers to GitHub Actions or GitLab CI YAML. Native lowering — one job per step, not thin wrappers. `sverka synth --target github`.
  </Card>
</CardGrid>

## How it works

```
Author → Plan → Run → Compile

1. Author:   Write sverka.config.ts (Construct, SDK, or Decorator API)
2. Plan:     sverka plan — bind Entry + inputs → Run Plan
3. Run:      sverka run — execute locally, get structured findings
4. Compile:  sverka synth --target github — lower to native CI YAML
```

## The token math

A typical verification task — build + lint + 3 security scanners + findings:

| Approach | Tool calls | Tokens |
|----------|-----------|--------|

| With Sverka | 1 command + 1 result | ~150 |
