Sverka is a provider-neutral workflow framework and execution platform for software verification. Author workflows in TypeScript through three equivalent APIs, execute them locally through a native engine, and compile the same Definition Graph to GitHub Actions or GitLab CI.

## What you get

<CardGrid stagger>
  <Card title="Three authoring surfaces" icon="seti:typescript">
    Construct, SDK, and Decorator APIs all produce the same Definition Graph.
  </Card>
  <Card title="Provider-neutral" icon="external">
    No GitHub or GitLab terms in your workflow. The Definition Graph is the source of truth.
  </Card>
  <Card title="Native execution" icon="rocket">
    Run through the native engine with host or container runtime. Topological scheduling, parallel steps.
  </Card>
  <Card title="Native target lowering" icon="seti:yaml">
    Lower to GitHub Actions or GitLab CI YAML. Not thin wrappers — real native lowering.
  </Card>
  <Card title="Capability model" icon="seti:settings">
    Plugin system declares what each target supports. Unsupported features produce diagnostics.
  </Card>
  <Card title="Conformance suite" icon="approve-check">
    §34 acceptance gate verifies all authoring surfaces produce equivalent graphs.
  </Card>
</CardGrid>
